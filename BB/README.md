# Backboard (BB) Commissioning

This directory contains data for characterizing the CASM backboards.

## Contents of the directory

- [**`s_params/`**](./s_params/README.md): Full 2-port S-parameter measurements of the backboards.
  - [Backboard Plot & Touchstone Data Viewer](./data_viewer.md)
  - [Backboard Diagnostic Log](./diagnostics.md)
- [**`noise_figure/`**](./noise_figure/README.md): Noise figure measurements of the backboards, using a calibrated noise source (ENR table).
